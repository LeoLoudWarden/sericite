# 命令行手册

这里收录 `sericite` 命令行的使用指南，面向直接运行 Sericite 程序、准备项目文件和配置运行环境的操作者。

指南按任务组织示例和解释；完整的命令参数、配置字段与退出行为由[命令行参考](reference/01-cli.zh-CN.md)统一列出。需要编写脚本本身时，请阅读[脚本手册](../scripting/README.zh-CN.md)；需要在自己的 Python 程序中管理 VM 生命周期时，应直接使用嵌入 API，而不是扩展命令行配置。

## 指南

| 页面 | 内容 |
|---|---|
| [运行程序](guides/01-running-programs.zh-CN.md) | 运行源文件和命令字符串、传递脚本参数、使用 REPL |
| [运行多文件项目](guides/02-projects.zh-CN.md) | 从入口文件启动项目，理解项目源码如何进入虚拟文件系统 |
| [配置 addon](guides/03-addons.zh-CN.md) | 用可信 Python 文件授予函数、预置文件并设置执行限额 |
| [输入、输出与错误诊断](guides/04-io-and-diagnostics.zh-CN.md) | 使用标准输入输出、读取诊断、处理退出码 |

第一次使用命令行时，按顺序阅读前两篇即可运行常见的单文件和多文件程序。只有需要宿主能力、初始文件或自定义配额时，才需要编写 addon 配置。
