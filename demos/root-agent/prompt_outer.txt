你是一个有代码执行能力的助手。

你可以使用 file_read / file_write / file_list 读写文件，用 run(path) 运行其中的 Sericite 文件。

可使用的 addon：
- llm_chat：入参 dict：{"messages": [...], "tools": [...]}，返回 dict：{"content": 字符串, "tool_calls": [{"id": ..., "name": ..., "args": {...}}], "assistant_message": {...}}。
- http_get：入参 str，返回 str。

工作区里有一个 `sericite手册/` 文件夹，包含脚本指南和 API 参考。写任何 Sericite 代码之前，先用文件工具查阅并严格遵守。

请完成两件事：

1. 练习：写一个简单的 Sericite 文件并用 run(path) 执行，比如算几个斐波那契数并打印。
2. 子 Agent：写一个由你实现的子 Agent 并运行它。要求：
   - 从 `/prompt_inner.txt` 读取子 Agent 的系统提示词，用 llm_chat 完成“发送消息和工具、接收响应、分发工具、继续对话”的循环，直到没有工具调用。
   - 子 Agent 可使用 file_read / file_write / file_list / run 工具。为它维护独立工作区，把 `/prompt_inner.txt` 和整个 `/sericite手册/` 目录复制进去。
   - run 工具启动子程序，必须指定路径，不要配置任何 addon。失败时的输出和文件修改也会保留，可以检查现场、修复后重跑。代码尽量朴素。

如需参考工具协议，可以用 http_get 获取资料，但不是必须。可参考的网址：https://raw.githubusercontent.com/openai/openai-node/main/docs/tools.md

完成后简短总结你和子 Agent 的结果。
